Harmony Haven Stable v2.2.0 – International Trip Planner
ฐานพัฒนา: v2.1.2 Performance + Project Expense Hotfix

ฟังก์ชันใหม่
1. สร้างโปรเจกต์ประเภท “เที่ยวต่างประเทศ”
2. ระบุประเทศ เมือง วันที่ สกุลเงิน สมาชิก และข้อมูลสำคัญ
3. แท็บ “วางแผนทริป” ภายในโปรเจกต์
4. ประมาณการรวม / อนุมัติหรือจองแล้ว / ใช้จริง / เฉลี่ยต่อคน
5. สมาชิกช่วยเสนอข้อมูลได้ตามหมวด:
   - เที่ยวบิน
   - ที่พัก
   - การเดินทาง
   - อาหาร
   - กิจกรรมและสถานที่
   - วีซ่าและประกัน
   - ช้อปปิ้งและของฝาก
   - ซิมและอินเทอร์เน็ต
   - เงินสำรอง
   - อื่น ๆ
6. แต่ละข้อเสนอเก็บราคา สกุลเงิน เรท เมือง วันที่ ลิงก์ ผู้เสนอ จำนวนคน และรายละเอียด
7. สถานะข้อเสนอ: เสนอ / เข้ารอบ / อนุมัติ / จองแล้ว / ไม่เลือก
8. โหวตและแสดงความคิดเห็นร่วมกัน
9. แผนรายวัน (วันที่ เวลา สถานที่ ผู้เสนอ และรายละเอียด)
10. สรุปประมาณการตามหมวดและเทียบกับงบเป้าหมาย
11. แชร์สรุปและลิงก์ตรงไปยังแท็บแผนทริป
12. โปรเจกต์เดิมสามารถกด “เปิดแผนทริป” เพื่อเปลี่ยนเป็นโปรเจกต์เที่ยวต่างประเทศได้

ข้อควรรู้เรื่องการแชร์
- การแก้ไขร่วมกันทำงานผ่าน Cloud State เดียวกัน
- ผู้รับลิงก์ต้องมีสิทธิ์ล็อกอินเข้า Harmony Haven ชุดเดียวกัน
- ลิงก์นี้ไม่ใช่ลิงก์สาธารณะสำหรับบุคคลภายนอกที่ไม่ต้องล็อกอิน

การติดตั้ง
1. วางไฟล์ทั้งหมดทับโปรเจกต์ v2.1.2
2. Deploy บน Vercel พร้อม Clear Build Cache
3. ไม่ต้องรัน SQL เพิ่ม
4. ปิดและเปิด PWA ใหม่ หรือกด Ctrl+F5 บนคอมพิวเตอร์
