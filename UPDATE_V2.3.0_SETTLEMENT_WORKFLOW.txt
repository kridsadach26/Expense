Harmony Haven Stable v2.3.0 — Professional Settlement Workflow

ปรับปรุงเฉพาะระบบสรุปการโอน/เคลียร์ยอดในโปรเจกต์

เพิ่ม:
- ติ๊ก ✓ ชำระเต็มยอดจากรายการแนะนำได้ทันที
- บันทึกชำระบางส่วน 25% / 50% / เต็มยอด หรือระบุจำนวนเอง
- เลือกผู้จ่ายและผู้รับเองได้ และมีปุ่มสลับผู้จ่าย/ผู้รับ
- ระบบตรวจว่าคู่ชำระเป็นทิศทางลูกหนี้ -> เจ้าหนี้จริง และป้องกันการจ่ายเกินยอดคงค้าง
- ประวัติการชำระ แสดงวันที่ ช่องทาง หมายเหตุ และยอด
- ยกเลิกรายการชำระได้โดยไม่ลบประวัติ (void) เพื่อให้ตรวจสอบย้อนหลังได้
- Progress แสดงยอดชำระแล้ว / ยอดคงเหลือ / เปอร์เซ็นต์เคลียร์
- ยอดสุทธิของสมาชิกและ “ใครต้องจ่ายใคร” หักยอดที่ชำระไปแล้วอัตโนมัติ
- เงินเคลียร์ระหว่างสมาชิกไม่ถูกนับเป็นรายรับหรือค่าใช้จ่ายซ้ำ
- ใช้ได้ทั้งโปรเจกต์ทั่วไปและทริปต่างประเทศที่มีเงินกองกลาง

ข้อมูล:
- ใช้ projects[].settlements ใน Cloud State เดิม
- ไม่ต้องรัน SQL เพิ่ม
- รองรับโปรเจกต์เดิมที่ยังไม่มี settlements
