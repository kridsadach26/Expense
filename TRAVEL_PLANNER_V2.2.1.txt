Harmony Haven Stable v2.2.1 – Trip Photos + Central Fund
วันที่จัดทำ: 30 กรกฎาคม 2026

ฐานที่ใช้
- พัฒนาต่อจาก Harmony Haven Stable v2.2.0 – International Trip Planner
- ไม่รื้อระบบ Cloud, Calendar, Category Intelligence หรือค่าใช้จ่ายเดิม
- ไม่ต้องรัน SQL เพิ่ม

ฟังก์ชันที่เพิ่ม
1) รูปภาพประกอบข้อเสนอท่องเที่ยว
- แนบจากกล้องหรือเลือกจากเครื่อง
- สูงสุด 4 รูปต่อข้อเสนอ
- บีบอัดอัตโนมัติ: ด้านยาวสูงสุดประมาณ 1,200 px และพยายามลดเหลือประมาณ 260 KB ต่อรูป
- แสดงตัวอย่างก่อนบันทึก ลบรูปที่เลือกผิดได้
- รูปแสดงในรายการข้อเสนอ และแตะเพื่อเปิดดูขนาดใหญ่
- แก้ไขข้อเสนอเดิมแล้วรูปเดิมยังอยู่

2) เงินกองกลางของทริป
- เลือก “ผู้ถือเงินกองกลาง / คนพาเที่ยวและจ่ายเงิน” ในตั้งค่าทริป
- บันทึกว่าใครส่งเงินมาเท่าไร วันที่ใด ช่องทางใด และผู้รับเงินคือใคร
- รองรับหลายสกุลเงินและเรทเป็นสกุลหลักของโปรเจกต์
- รายการรับเงินกองกลางไม่ถูกนับเป็นรายรับหรือค่าใช้จ่ายซ้ำ
- แสดงยอดรับเข้ากองกลาง ยอดใช้จากกองกลาง และยอดคงเหลือ
- แสดงประวัติการส่งเงินแยกรายคน พร้อมแก้ไขและลบ

3) เชื่อมกับค่าใช้จ่ายในโปรเจกต์
- โปรเจกต์ทริปมีช่อง “แหล่งเงิน” ตอนเพิ่มค่าใช้จ่าย
- เลือกได้ระหว่าง “เงินกองกลาง” และ “เงินส่วนตัวผู้จ่าย”
- ถ้าเลือกเงินกองกลาง ระบบเลือกผู้ถือเงินกองกลางเป็นคนจ่ายให้อัตโนมัติ
- ค่าใช้จ่ายกองกลางแสดงป้าย 💰 กองกลางในรายการ
- สรุปกองกลางรายคนแสดงยอดที่ส่งมา ยอดที่ต้องรับผิดชอบ และยอดที่ควรเติมหรือรับคืน
- ค่าใช้จ่ายกองกลางแยกออกจากสรุปเงินส่วนตัว เพื่อป้องกันการคิดซ้ำ

โครงสร้างข้อมูลใหม่ใน Cloud State
project.travelPlan.fundHolderId
project.travelPlan.fundContributions[]
project.travelPlan.proposals[].images[]
project.expenses[].fundSource = "central" | "personal"

การติดตั้ง
1. สำรองหรือ Commit โปรเจกต์ปัจจุบัน
2. วางไฟล์ทั้งหมดจาก ZIP ทับเวอร์ชัน v2.2.0
3. Deploy บน Vercel โดยเลือก Clear Build Cache
4. ไม่ต้องรัน SQL เพิ่ม
5. ปิด PWA จากหน้ารวมแอปแล้วเปิดใหม่ หรือกด Ctrl+F5 บนคอมพิวเตอร์

หมายเหตุด้านประสิทธิภาพ
- รูปข้อเสนอเก็บใน Cloud State เดียวกับข้อมูลแผนทริป จึงจำกัดไว้ 4 รูปและบีบอัดอัตโนมัติ
- ไม่ควรแนบภาพซ้ำจำนวนมากในทุกข้อเสนอ เพื่อให้เปิดแอปได้รวดเร็ว
