Harmony Haven v2.2.1 Test Report

ผ่านการตรวจสอบ
- JavaScript syntax: node --check ผ่าน
- HTML id: ไม่พบ id ซ้ำ
- ตรวจ id ใหม่ที่ JavaScript ใช้งาน: ครบทั้งหมด
- ตรวจจำนวน function สำคัญ: อย่างละ 1 ชุด ไม่เกิด function ซ้ำ
- ทดสอบสูตรกองกลางด้วยข้อมูลจำลอง:
  รับเงินรวม 4,000 / ใช้ 3,000 / คงเหลือ 1,000 ผ่าน
  สมาชิกส่งเกินส่วนรับผิดชอบ 500 + 500 แสดงยอดควรได้คืนถูกต้อง
- ทดสอบ safe image filter: รับเฉพาะ data:image แบบ JPEG/PNG/WebP และปฏิเสธ URL ที่ไม่ปลอดภัย
- ตรวจโครงสร้าง ZIP และไฟล์หลักผ่าน

รายการที่ควรทดสอบหลัง Deploy
1. ตั้งผู้ถือเงินกองกลางในตั้งค่าทริป
2. เพิ่มเงินกองกลางจากสมาชิกอย่างน้อย 2 คน
3. เพิ่มข้อเสนอพร้อมรูปจากกล้องและคลังรูป
4. แก้ไขข้อเสนอและตรวจว่ารูปเดิมยังอยู่
5. เพิ่มค่าใช้จ่ายโดยเลือกเงินกองกลาง
6. ตรวจยอดรับเข้า / ใช้ / คงเหลือ และสรุปรายคน
7. เพิ่มค่าใช้จ่ายด้วยเงินส่วนตัว และตรวจว่ายังอยู่ในแท็บยอดคงเหลือตามปกติ
