Harmony Haven Stable v2.1.2
Performance + Project Expense Hotfix

แก้ไขหลัก
1. เปิดแอปเร็วขึ้น
- เพิ่ม IndexedDB cache สำหรับ Cloud State
- ครั้งถัดไปเปิดจากข้อมูลล่าสุดในเครื่องก่อน แล้วตรวจ Cloud เบื้องหลัง
- ลดเวลารอ Cloud สูงสุดเหลือ 12 วินาที
- ไม่รอการบันทึก Cloud ครั้งแรกก่อนเปิดหน้าหลัก
- เมื่อ Cloud ช้า แอปยังใช้งานข้อมูลแคชได้

2. แก้การเพิ่มค่าใช้จ่ายในโปรเจกต์
- ตรวจผู้ร่วมหารเฉพาะภายในหน้าต่างโปรเจกต์ ป้องกัน selector ชนกับส่วนอื่น
- ตรวจจำนวนเงิน หมวด คนจ่าย ผู้ร่วมหาร รูปหลักฐาน แยกข้อความชัดเจน
- ชื่อรายการเว้นว่างได้ โดยใช้ชื่อหมวดละเอียดแทนอัตโนมัติ
- วันที่ว่างจะใช้วันที่ปัจจุบัน
- ป้องกันกดบันทึกซ้ำ
- รองรับข้อมูลโปรเจกต์เก่าที่ไม่มี expenses array
- แสดง Toast เมื่อบันทึกสำเร็จ
- เก็บ cache ทันทีหลังบันทึก ลดโอกาสข้อมูลหายหาก Cloud ช้า

การติดตั้ง
- วางไฟล์ทั้งหมดทับ v2.1.1
- ไม่ต้องรัน SQL เพิ่ม
- Deploy แบบ Clear Build Cache
- ปิด PWA จาก Recent Apps แล้วเปิดใหม่ หรือ Safari กด Reload

หมายเหตุ
การเปิดครั้งแรกหลังอัปเดตยังต้องโหลด Cloud หนึ่งครั้งเพื่อสร้าง cache หลังจากนั้นจะเร็วขึ้นชัดเจน
