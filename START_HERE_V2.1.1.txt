Harmony Haven Stable v2.1.1 — Task Creation Hotfix

ฐานเวอร์ชัน:
- พัฒนาต่อจาก Harmony Haven Stable v2.1.0 Category Intelligence
- คงฟังก์ชันหมวดหมู่ 3 ระดับ, Tag, ความจำร้านค้า, โปรเจกต์, ปฏิทิน และ Cloud State เดิม

ปัญหาที่แก้:
1. กดบันทึกงาน/กำหนดการใหม่แล้วไม่สำเร็จบนระบบจริงที่เปิดผ่าน HTTPS
2. สาเหตุคือฟังก์ชันสร้าง UUID เรียกตัวเองซ้ำไม่สิ้นสุดเมื่อเบราว์เซอร์รองรับ crypto.randomUUID()
3. เปลี่ยนให้เรียก crypto.randomUUID() โดยตรง และมี UUID fallback สำหรับเบราว์เซอร์เก่า
4. เปลี่ยนการเปิด/ปิดหน้าต่างงานและศูนย์แจ้งเตือนให้ค้นจาก id โดยตรง ไม่พึ่งตัวแปร global ที่บางเบราว์เซอร์หรือ PWA อาจไม่มี
5. เพิ่มการตรวจชื่อและวันที่ก่อนบันทึก พร้อมป้องกันการกดบันทึกซ้ำ
6. เพิ่มข้อความแจ้งข้อผิดพลาดที่อ่านได้ หากเปิดหรือบันทึกหน้าต่างงานไม่สำเร็จ

1. สำรองหรือ Commit โปรเจกต์ปัจจุบันก่อน
